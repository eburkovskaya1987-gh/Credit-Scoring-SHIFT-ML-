# SHIFT ML 2026 - Credit Scoring (ROC-AUC: 0.757)

Решение задачи бинарной классификации для предсказания дефолта по кредитным займам.

## Ключевые этапы:
1.  **EDA и очистка:** Удаление признаков с >30% пропусков, заполнение числовых медианой, категориальных — 'unknown'.
2.  **Feature Engineering:** Работа с 84 признаками (категориальные, числовые, даты).
3.  **Моделирование:** Использование CatBoostClassifier с указанием категориальных признаков (без OHE).
4.  **Борьба с дисбалансом:** Применение `auto_class_weights='Balanced'` (улучшило ROC-AUC с 0.68 до 0.75).
5.  **Feature Selection:** Удаление 13 признаков с нулевой важностью на основе `get_feature_importance`.
6.  **Кросс-валидация:** 3-fold CV, средний ROC-AUC = 0.7572 (отклонение +/- 0.0159).

## Стек:
Python (Pandas, NumPy), CatBoost, Scikit-learn, Matplotlib/Seaborn.
