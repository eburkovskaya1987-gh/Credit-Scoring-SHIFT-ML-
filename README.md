# Credit Scoring - SHIFT ML 2026 (Решение задачи кредитного скоринга)

Репозиторий содержит два подхода к решению задачи бинарной классификации (предсказание дефолта по кредитным займам) на данных соревнования SHIFT ML 2026. 

Цель: Предсказать вероятность дефолта клиента (целевая переменная `итоговый_статус_займа`).

## 📁 Структура репозитория

В репозитории представлены два Jupyter Notebook, которые демонстрируют эволюцию подхода к моделированию:

1.  **`ROC_AUC_0_7702.ipynb`** (Базовое решение)
    *   Первичный EDA и очистка данных (удаление колонок с >30% пропусков, заполнение медианой и 'unknown').
    *   Базовое моделирование с использованием `CatBoostClassifier` и указанием категориальных признаков.
    *   Борьба с дисбалансом классов через `auto_class_weights='Balanced'`.
    *   Использование Feature Importance для удаления 13 "мусорных" признаков.

2.  **`shap_optuna.ipynb`** (Продвинутое решение)
    *   **Feature Engineering (33 новых признака):** Создание финансовых коэффициентов (Debt-to-Income, Utilization Ratio, Delinquency Density, Financial Stress Score) и логарифмических трансформаций.
    *   **SHAP-анализ:** Интерпретация модели с помощью `shap.TreeExplainer`. Выявление и удаление 16 признаков с нулевой важностью.
    *   **Optuna:** Автоматизированный подбор гиперпараметров (depth, learning_rate, l2_leaf_reg) с использованием 5-fold кросс-валидации.

## 📊 Результаты

| Ноутбук | Метрика (ROC-AUC) | Ключевая особенность |
| :------ | :---------------- | :------------------- |
| `ROC_AUC_0_7702.ipynb` | **0.7572** | Базовая очистка, CatBoost, балансировка классов |

*Примечание:* Разница в ROC-AUC между ноутбуками находится в пределах статистической погрешности. Продвинутый ноутбук показывает не столько прирост метрики, сколько **интерпретируемость** (SHAP) и глубину проработки признаков (Feature Engineering).
